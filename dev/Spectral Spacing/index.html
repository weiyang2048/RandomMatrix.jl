RandomMatrix.wignersurmise — Function
wignersurmise(s ; beta)

  • beta : default 1,

    1 for the spacing density corresponds to GOE(2)

    $p_1(s)=\frac{\pi s}{2} e^{-\pi s^{2} / 4}$

    2 for the spacing density corresponds to GUE(2)

    $p_2(s)=\frac{32 s^{2}}{\pi^{2}} e^{-4 s^{2} / \pi}$

  • For more info see Wigner surmise on Wikipedia

Examples

Evaluate Wigner surmise for GOE at 2

wignersurmise(2)

0.1357605281502967

Evaluate Wigner surmise for GUE at 2

wignersurmise(2,beta=2)

0.07962814352725955

RandomMatrix.numberVariance — Function
numberVariance(E, l::Float64)

Number variance of the spectrum E at unfolded interval length l. E is first unfolded (see unfoldedeigvals); for each unfolded eigenvalue $e$ let $n_e(l)$ be the number of other unfolded eigenvalues within distance $l/2$ of $e$. The return value is the spectral average of $(n_e(l) - l)^2$ — the empirical analogue of $\Sigma^2(l) = \langle (n(l) - \langle n(l)\rangle)^2 \rangle$, which grows only logarithmically in $l$ for rigid (random-matrix) spectra and linearly for uncorrelated (Poisson) spectra.

Examples

numberVariance(sort(randn(50)), 2.0)
