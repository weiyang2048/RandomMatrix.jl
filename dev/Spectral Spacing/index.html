RandomMatrix.wignersurmise — Function
wignersurmise(s ; beta)

  • beta : default 1,

    1 for the spacing density corresponds to GOE(2)

    $p_1(s)=\frac{\pi s}{2} e^{-\pi s^{2} / 4}$

    2 for the spacing density corresponds to GUE(2)

    $p_2(s)=\frac{32 s^{2}}{\pi^{2}} e^{-4 s^{2} / \pi}$

  • For more info see Wigner surmise on Wikipedia

RandomMatrix.numberVariance — Function
numberVariance(E, l::Float64)

Number variance of the spectrum E at unfolded interval length l. E is first unfolded (see unfoldedeigvals); for each unfolded eigenvalue $e$ let $n_e(l)$ be the number of other unfolded eigenvalues within distance $l/2$ of $e$. The return value is the spectral average of $(n_e(l) - l)^2$ — the empirical analogue of $\Sigma^2(l) = \langle (n(l) - \langle n(l)\rangle)^2 \rangle$, which grows only logarithmically in $l$ for rigid (random-matrix) spectra and linearly for uncorrelated (Poisson) spectra.

Examples

numberVariance(sort(randn(50)), 2.0)

Adjacent gap ratios

The adjacent gap ratio $r_n = \min(s_n, s_{n+1}) / \max(s_n, s_{n+1})$ of consecutive spacings needs no unfolding — the local level density cancels in the ratio — so its mean is a one-number diagnostic of the local statistics: $\langle r \rangle \approx 0.3863$ for uncorrelated (Poisson) levels, $0.5307$ (GOE), $0.5996$ (GUE) and $0.6744$ (GSE) (Atas, Bogomolny, Giraud & Roux, Phys. Rev. Lett. 110, 084101 (2013)).

RandomMatrix.gapRatios — Function
gapRatios(E)

Adjacent gap ratios of the spectrum E: with the spacings $s_n = E_{n+1} - E_n$ of the sorted eigenvalues,

\[r_n = \frac{\min(s_n, s_{n+1})}{\max(s_n, s_{n+1})} \in [0, 1].\]

Unlike the spacing distribution or numberVariance, the ratio needs no unfolding: the local level density cancels between consecutive spacings, so gapRatios applies directly to a raw spectrum. A ratio of exactly 0 is returned where both spacings of a pair vanish (a triple degeneracy). E is not mutated. See meanGapRatio for the standard summary statistic and its exact reference values.

Reference: Atas, Bogomolny, Giraud & Roux, "Distribution of the ratio of consecutive level spacings in random matrix ensembles", Phys. Rev. Lett. 110, 084101 (2013).

Examples

gapRatios([0.0, 1.0, 3.0, 4.0])   # spacings 1, 2, 1 -> [0.5, 0.5]

RandomMatrix.meanGapRatio — Function
meanGapRatio(E)

Mean adjacent gap ratio $\langle r \rangle$ of the spectrum E (see gapRatios). Because the ratio needs no unfolding, this single number is the standard first diagnostic for the local statistics of a spectrum. Exact / large-$n$ reference values (Atas et al. 2013):

  • uncorrelated (Poisson) levels: $2 \log 2 - 1 \approx 0.3863$,
  • GOE ($\beta = 1$): $\approx 0.5307$,
  • GUE ($\beta = 2$): $\approx 0.5996$,
  • GSE ($\beta = 4$): $\approx 0.6744$.

Finite spectra sit slightly above these bulk values; compare bulk (interior) eigenvalues for a sharp test.

Examples

meanGapRatio([0.0, 1.0, 3.0, 4.0])   # 0.5

RandomMatrix.fitGapRatioBeta — Function
fitGapRatioBeta(E)

Effective Dyson index $\beta$ of the spectrum E, estimated by inverting the mean adjacent gap ratio: returns the $\beta$ whose Atas et al. (2013) Wigner-like surmise mean $\langle r \rangle(\beta)$ equals meanGapRatio(E). The surmise mean is monotone in $\beta$, so the inversion is a bisection on $[0, 64]$.

The estimate is an effective index, useful for intermediate-statistics spectra (crossover ensembles, critical statistics): it is calibrated on the 3-level surmise, not the exact large-$n$ ratio distribution, so it carries a small systematic bias (seeded BetaHermite calibration: true $\beta = 0.5, 1, 1.5, 2, 3, 4$ recovered as $\approx 0.39, 0.93, 1.55, 1.94, 2.77, 4.01$ from pooled bulk spectra). A mean ratio at or below the surmise's $\beta = 0$ value $\approx 0.4086$ — which includes the exact Poisson mean $2 \log 2 - 1 \approx 0.3863$ — returns 0.0; a mean ratio the surmise reaches only as $\beta \to \infty$ returns the bracket cap 64.0.

Reference: Atas, Bogomolny, Giraud & Roux, Phys. Rev. Lett. 110, 084101 (2013).

Examples

fitGapRatioBeta([0.0, 1.0, 3.0, 4.0])   # <r> = 0.5 -> beta ≈ 0.63

RandomMatrix.fitGapRatioBetaCI — Function
fitGapRatioBetaCI(E; level=0.95, nboot=1000, blocklength=nothing, method=:percentile, rng=Random.default_rng())

Sampling uncertainty for fitGapRatioBeta: a circular block bootstrap over the observed spacing sequence of E. Blocks of blocklength consecutive spacings (default $\max(2, \mathrm{round}(\sqrt{m}))$ for $m$ spacings) are resampled with replacement until a full-length spacing sequence is rebuilt, so each replicate's adjacent gap ratios keep the consecutive-pairing $r_n = \min(s_n, s_{n+1}) / \max(s_n, s_{n+1})$ and the short-range dependence between neighbouring ratios. Each replicate's mean ratio is inverted through the same Atas et al. (2013) surmise as fitGapRatioBeta.

With method = :percentile (the default) the returned interval is the percentile band of the replicate estimates at level. With method = :bca it is the BCa (bias-corrected and accelerated) band of Efron (J. Amer. Statist. Assoc. 82, 1987): the percentile levels are adjusted by a bias correction $z_0$ from the replicate distribution and an acceleration $a$ from a jackknife over the same spacing blocks the bootstrap resamples, so the blocking is consistent between the two. Prefer BCa when the replicate distribution is skewed or the point estimate sits off its centre (the usual case for short spectra, where the surmise inversion is strongly nonlinear); prefer the percentile band when a transparent, assumption-light summary is wanted. If every replicate equals the point estimate (e.g. an equal-spaced spectrum) both bands collapse onto it.

Returns a NamedTuple (beta, lo, hi, level, nboot, blocklength, method), where beta is the point estimate fitGapRatioBeta(E). The band measures sampling variation of $\langle r \rangle$ only: it does not remove the surmise's systematic bias documented in fitGapRatioBeta, so for short spectra the band — not the point — is the honest summary.

Calibration (seeded BetaHermite bulk spectra, 20 trials per config, 95% level, nboot = 400): at bulk size 180 the percentile band covered the truth 20/20 ($\beta = 1$) and 18/20 ($\beta = 2$), the BCa band 18/20 and 17/20; at bulk size 100 (short spectra) percentile covered 18/20 ($\beta = 1$) and 19/20 ($\beta = 2$), BCa 19/20 at both — the two bands are comparable at these sizes, and neither removes the surmise bias. In this package's test suite, bulk spectra of BetaHermite(2, 300) recover $\beta = 2$ inside the 95% band under both methods, and the band for an equal-spaced spectrum collapses onto the bracket cap.

Examples

fitGapRatioBetaCI(sort(randn(200)); rng=Random.MersenneTwister(1))
fitGapRatioBetaCI(sort(randn(200)); method=:bca, rng=Random.MersenneTwister(1))
source

fitGapRatioBetaCI reports the percentile band by default; pass method = :bca for the BCa (bias-corrected and accelerated) band — the percentile levels adjusted by the replicate distribution's bias correction and a jackknife acceleration over the same spacing blocks the bootstrap resamples. Prefer BCa for short spectra, where the replicate distribution is skewed; the docstring records the seeded coverage calibration of both bands.

using RandomMatrix, Random
E = rand(MersenneTwister(42), BetaHermite(2, 200))
meanGapRatio(E[41:160])   # bulk of a GUE spectrum: near the 0.5996 anchor

Spectral form factor

The spectral form factor is the dynamical companion of the spacing statistics above: where numberVariance probes level correlations in the spectrum domain, spectralFormFactor probes them in the time domain, through the dip–ramp–plateau structure of the ensemble-averaged form factor. Both functions take a beta keyword for the finite-temperature form factor $|Z(\beta + it)|^2 / Z(\beta)^2$ (the default beta = 0 is the zero-temperature case).

RandomMatrix.spectralFormFactor — Function
spectralFormFactor(E, t; beta=0.0, unfold=false, deg=10, goe=false)

Spectral form factor of the spectrum E at time t and inverse temperature beta,

\[g(t, \beta) = \frac{|Z(\beta + i t)|^2}{Z(\beta)^2}, \qquad Z(\beta + i t) = \sum_{j=1}^{N} e^{-(\beta + i t) E_j},\]

with N = length(E). t may be a single real number (returns a Float64) or a vector of times (returns a Vector{Float64}).

At the default beta = 0 this is the zero-temperature form factor $|\sum_j e^{-i t E_j}|^2 / N^2$. At beta > 0 the levels carry thermal weights $w_j = e^{-\beta E_j}$: $g(0, \beta) = 1$ still holds, but the late-time plateau — the time average of g, for distinct levels — rises from $1/N$ to the participation ratio $\sum_j w_j^2 / (\sum_j w_j)^2$ of the weights, and the dip below the plateau becomes shallower as fewer levels effectively contribute. beta is in inverse units of the levels as given (after unfolding, if requested — unfolded levels run to $O(N)$, so a comparable thermal effect there needs beta of order $1/N$). beta must be finite and nonnegative.

The levels are used exactly as given: no unfolding is applied unless unfold=true, in which case the spectrum is first passed through unfoldedeigvals (with its deg and goe keywords, on a copy — E is never mutated). The dip–ramp–plateau structure of random-matrix spectra — an early decay, a dip below the plateau, a roughly linear ramp, and saturation at the plateau beyond the Heisenberg time — is a property of the ensemble-averaged form factor of unfolded levels; see ensembleSpectralFormFactor. For uncorrelated (Poisson) levels the ensemble average instead decays straight to the plateau and stays there: no dip, no ramp.

This is the spectral form factor of Cotler et al., "Black holes and random matrices", J. High Energy Phys. 2017(5):118, arXiv:1611.04650, whose $\beta = 0$ case the original version of this function computed.

Examples

spectralFormFactor([0.0, 1.0], π)              # the two phases cancel: 0
spectralFormFactor([0.0, 1.0], π; beta=1.0)    # ((1 - e^-1)/(1 + e^-1))^2 ≈ 0.2136
spectralFormFactor(rand(MersenneTwister(1), BetaHermite(2, 50)), 0.5)
source
RandomMatrix.ensembleSpectralFormFactor — Function
ensembleSpectralFormFactor(spectra, t; beta=0.0, unfold=false, deg=10, goe=false)

Ensemble-averaged spectral form factor of a collection of spectra at inverse temperature beta (see spectralFormFactor for the definition and the role of beta), with the disconnected/connected decomposition of Cotler et al. (J. High Energy Phys. 2017(5):118).

spectra is a vector of spectra, all of the same length N (for example, repeated draws from BetaHermite). Writing $A_s(t) = Z_s(\beta + i t) / Z_s(\beta)$ for the normalized amplitude of spectrum s — each spectrum is normalized by its own $Z_s(\beta)$, so at beta = 0 this is exactly the original zero-temperature decomposition — the return value is the NamedTuple

(total = ..., connected = ..., disconnected = ...)

where total is the ensemble mean of the single-spectrum form factor spectralFormFactor, $total = \langle |A(t)|^2 \rangle$; disconnected is the part carried by the average density alone, $|\langle A(t) \rangle|^2$; and connected is the remainder, total - disconnected, which isolates the two-level correlations — for unfolded random-matrix spectra at beta = 0 it is the ramp, rising from near zero to the plateau $1/N$ at the Heisenberg time, while for uncorrelated levels it sits at $1/N$ at all times. At t = 0 every amplitude is 1, so total == disconnected == 1 and connected == 0, at any beta. With a single spectrum the decomposition is trivial: disconnected == total and connected == 0.

As in spectralFormFactor, the levels are used as given unless unfold=true, which first applies unfoldedeigvals to each spectrum.

source
using RandomMatrix, Random
specs = [rand(MersenneTwister(42), BetaHermite(2, 100)) for _ in 1:50]
parts = ensembleSpectralFormFactor(specs, [0.5, 2.0, 6.3]; unfold=true)
parts.total   # decays, ramps, and approaches the plateau 1/100
