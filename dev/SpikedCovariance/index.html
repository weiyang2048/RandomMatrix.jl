Spiked Covariance and the BBP Transition

In a spiked covariance model the population covariance has a bulk of eigenvalues at $\sigma^2$ plus a few larger spikes. With aspect ratio $\gamma = p/n$, the Baik–Ben Arous–Péché (BBP) transition says a spike $\ell$ is visible in the sample covariance — as an outlier eigenvalue with an eigenvector correlated with the population direction — only when $\ell > \sigma^2 (1 + \sqrt\gamma)$. Below the threshold the spike is swallowed by the Marčenko–Pastur bulk.

RandomMatrix.bbpThreshold — Function
bbpThreshold(gamma; sigma=1.0)

Critical population eigenvalue for the BBP phase transition in a spiked covariance model with aspect ratio gamma = p/n and bulk (noise) variance sigma^2. A population spike l yields an outlier sample eigenvalue only if l > bbpThreshold(gamma) = sigma^2 * (1 + sqrt(gamma)).

source
bbpThreshold(points, masses, gamma)
bbpThreshold(mu::FreeMeasure, gamma)
bbpThreshold(d::UnivariateDistribution, gamma; hpoints=401)

Critical population eigenvalue for the BBP phase transition when the population covariance has limiting spectral distribution H (aspect ratio gamma = p/n): a spike l yields an outlier sample eigenvalue only if l > bbpThreshold(...). The threshold is the unique minimizer lc of the dTransform on (sup supp H, Inf), i.e. the unique root there of 1 = gamma * int t^2 / (lc - t)^2 dH(t), found by bisection; the bulk edge the outlier separates from is dTransform(lc, ...), the upper support edge of silversteinLaw(H, gamma). At H = delta_{sigma^2} this is sigma^2 (1 + sqrt(gamma)), the scalar bbpThreshold(gamma; sigma). H is given in the three input forms of silversteinLaw.

source
RandomMatrix.spikeLocation — Function
spikeLocation(l, gamma; sigma=1.0)

Almost-sure limit of the sample eigenvalue generated by a population spike l (an eigenvalue of the population covariance, bulk at sigma^2) with aspect ratio gamma = p/n:

l * (1 + gamma * sigma^2 / (l - sigma^2))     if l > sigma^2 (1 + sqrt(gamma))

Below the BBP threshold the spike sticks to the upper Marcenko-Pastur edge sigma^2 (1 + sqrt(gamma))^2, which is what this returns.

source
spikeLocation(l, points, masses, gamma)
spikeLocation(l, mu::FreeMeasure, gamma)
spikeLocation(l, d::UnivariateDistribution, gamma; hpoints=401)

Almost-sure limit of the sample eigenvalue generated by a population spike l when the population covariance has limiting spectral distribution H and aspect ratio gamma = p/n:

dTransform(l, H, gamma)     if l > bbpThreshold(H, gamma)

Below the generalized BBP threshold the spike sticks to the upper bulk edge dTransform(lc, H, gamma) – the upper support edge of silversteinLaw(H, gamma) – which is what this returns. This extends the scalar spikeLocation (the case H = delta_{sigma^2}) to a general population, with H in the three input forms of silversteinLaw.

source
RandomMatrix.spikeOverlap — Function
spikeOverlap(l, gamma; sigma=1.0)

Almost-sure limit of the squared overlap |dot(u_hat, u)|^2 between the sample eigenvector of the outlier and its population counterpart, for a population spike l with aspect ratio gamma = p/n and bulk variance sigma^2:

(1 - gamma * sigma^4 / (l - sigma^2)^2) / (1 + gamma * sigma^2 / (l - sigma^2))

Zero below the BBP threshold: the sample eigenvector is asymptotically orthogonal to the population direction.

source
spikeOverlap(l, points, masses, gamma)
spikeOverlap(l, mu::FreeMeasure, gamma)
spikeOverlap(l, d::UnivariateDistribution, gamma; hpoints=401)

Almost-sure limit of the squared overlap |dot(u_hat, u)|^2 between the sample eigenvector of the outlier and its population counterpart, for a population spike l against a population spectral distribution H with aspect ratio gamma = p/n:

l * D'(l) / D(l),   D = dTransform(., H, gamma),
D'(l) = 1 - gamma * int t^2 / (l - t)^2 dH(t)

Zero below the generalized BBP threshold: the sample eigenvector is asymptotically orthogonal to the population direction. This extends the scalar spikeOverlap (the case H = delta_{sigma^2}), with H in the three input forms of silversteinLaw.

RandomMatrix.estimateSpike — Function
estimateSpike(lambda, gamma; sigma=1.0)

Estimate the population spike l from an observed outlier sample eigenvalue lambda, by inverting spikeLocation:

l = sigma^2 * ((lam + 1 - gamma) + sqrt((lam + 1 - gamma)^2 - 4 lam)) / 2,
lam = lambda / sigma^2

For lambda at or below the Marcenko-Pastur edge the spike is not identifiable and the BBP threshold value is returned.

source
estimateSpike(lambda, points, masses, gamma)
estimateSpike(lambda, mu::FreeMeasure, gamma)
estimateSpike(lambda, d::UnivariateDistribution, gamma; hpoints=401)

Estimate the population spike l from an observed outlier sample eigenvalue lambda, by inverting spikeLocation for a general population spectral distribution H: the unique l above bbpThreshold(H, gamma) with dTransform(l, H, gamma) = lambda, found by bisection on the increasing branch of the D-transform. For lambda at or below the upper bulk edge of silversteinLaw(H, gamma) the spike is not identifiable and the threshold value is returned, as in the scalar estimateSpike. H is given in the three input forms of silversteinLaw.

source
RandomMatrix.spikeVariance — Function
spikeVariance(l, gamma, n; sigma=1.0, real=true)

Asymptotic variance of the outlier sample eigenvalue generated by a supercritical population spike l (Paul 2007): with lr = l / sigma^2,

Var(lambda_hat) = sigma^4 * 2 lr^2 (1 - gamma / (lr - 1)^2) / n

for real data; sqrt(n) (lambda_hat - spikeLocation(l, gamma)) is asymptotically centred normal with variance n * Var(lambda_hat). For complex data (real=false) the variance is halved. Returns NaN at or below the BBP threshold, where the fluctuations are Tracy-Widom rather than Gaussian.

source
RandomMatrix.randSpikedCovariance — Function
randSpikedCovariance(p, n, spikes; sigma=1.0)

Sample covariance matrix (1/n) X X' of p x n Gaussian data whose population covariance has eigenvalues spikes (a vector of spike eigenvalues, each > sigma^2) on top of a bulk at sigma^2, with random ( Haar ) population eigenvectors. Returns a symmetric p x p matrix.

Examples

RandomMatrix.dTransform — Function
dTransform(l, points, masses, gamma)
dTransform(l, mu::FreeMeasure, gamma)
dTransform(l, d::UnivariateDistribution, gamma; hpoints=401)

The D-transform of the population spectral distribution H at the spike l, in the normalization of Baik & Silverstein (2006) and Couillet & Liao (2022): for l above the top of the support of H,

\[\mathcal D(l) = l \left(1 + \gamma \int \frac{t}{l - t} \, dH(t)\right), \qquad \gamma = p/n .\]

Its role is the outlier map of the generalized spiked covariance model: a population spike at l produces a sample outlier at dTransform(l, ...) exactly when l exceeds bbpThreshold for this H (the unique minimizer of dTransform on (sup supp H, Inf)), and the outlier's squared eigenvector overlap is l * D'(l) / D(l) with D'(l) = 1 - gamma * int t^2 / (l - t)^2 dH(t). Equivalently dTransform(l, ...) = z(-1/l) for the companion inverse map z(m) = gamma * int t / (1 + t m) dH(t) - 1/m of silversteinLaw, i.e. the outlier lambda is characterized by munderline(lambda) = -1/l. At H = delta_{sigma^2} it reduces to l * (1 + gamma * sigma^2 / (l - sigma^2)), the map inside the scalar spikeLocation.

H is given in the three input forms of silversteinLaw: discrete points/masses (the integral is then an exact finite sum), a FreeMeasure (its nodes and weights), or a Distributions law supported on [0, Inf), discretized on an equal-weight quantile grid of hpoints points first. Throws an ArgumentError for l at or below the top of the support of H, where the integral has its pole.

source

Worked example

At $\gamma = 0.5$ a spike of $\ell = 4$ is well above the BBP threshold, so it should appear as an outlier near spikeLocation(4, 0.5) = 4.667 with eigenvector overlap about 0.81; a spike of $\ell = 1.3$ is below the threshold and sticks to the Marčenko–Pastur edge $(1 + \sqrt\gamma)^2 \approx 2.914$.

using RandomMatrix
gamma = 0.5
(threshold = bbpThreshold(gamma), loc = spikeLocation(4.0, gamma),
 overlap = round(spikeOverlap(4.0, gamma), digits = 3),
 recovered = estimateSpike(spikeLocation(4.0, gamma), gamma))
(threshold = 1.7071067811865475, loc = 4.666666666666667, overlap = 0.81, recovered = 4.0)

A seeded simulation agrees, within the fluctuation scale sqrt(spikeVariance(4, 0.5, 400)) ≈ 0.27 given by Paul's formula:

S = randSpikedCovariance(200, 400, [4.0])
round(eigmax(S), digits = 2)
4.45

The general population case

The bulk need not sit at a single point. When the population eigenvalues have a general limiting distribution $H$ (the setting of silversteinLaw), Baik & Silverstein (2006) give the transition through the D-transform $\mathcal D(\ell) = \ell \left(1 + \gamma \int t \, / \, (\ell - t) \, dH(t)\right)$: a spike $\ell$ produces an outlier at $\mathcal D(\ell)$ exactly when $\ell$ exceeds the unique minimizer of $\mathcal D$ — the generalized bbpThreshold — and the squared eigenvector overlap is $\ell \mathcal D'(\ell) / \mathcal D(\ell)$. The four functions above accept H in the same three input forms as silversteinLaw: discrete points/masses, a FreeMeasure, or a Distributions law. At $H = \delta_{\sigma^2}$ they reduce exactly to the scalar formulas of the previous section.

For a population split evenly between $1$ and $4$ at $\gamma = 0.5$, the threshold is $\ell_c \approx 6.01$ — a spike must clear not just the population bulk (top at $4$) but the D-transform minimum — and a spike of $10$ separates to $11.94$, while a spike of $2$ is absorbed at the bulk edge $9.30$ (the upper edge of silversteinLaw for this $H$):

Hp, Hm = [1.0, 4.0], [0.5, 0.5]
(threshold = round(bbpThreshold(Hp, Hm, gamma), digits = 3),
 loc = round(spikeLocation(10.0, Hp, Hm, gamma), digits = 3),
 overlap = round(spikeOverlap(10.0, Hp, Hm, gamma), digits = 3),
 recovered = round(estimateSpike(spikeLocation(10.0, Hp, Hm, gamma), Hp, Hm, gamma), digits = 6),
 stuck = round(spikeLocation(2.0, Hp, Hm, gamma), digits = 3))
(threshold = 6.01, loc = 11.944, overlap = 0.742, recovered = 10.0, stuck = 9.3)

A seeded simulation with a formed population covariance (bulk eigenvalues $1$ and $4$, one spike of $10$) agrees:

p, n = 400, 800
evals = vcat(fill(1.0, 200), fill(4.0, 199), [10.0])
Q = Matrix(qr(randn(p, p)).Q)
A = Q * Diagonal(sqrt.(evals)) * Q'
X = A * randn(p, n) / sqrt(n)
round(eigmax(Symmetric(X * X')), digits = 2)
11.19

The rectangular case

For singular values of rectangular data the transition is at $d > \gamma^{1/4}$ (Benaych-Georges & Nadakuditi).

RandomMatrix.svdThreshold — Function
svdThreshold(gamma)

Critical population singular value for the rectangular BBP transition (Benaych-Georges & Nadakuditi): for p x n data with gamma = p/n <= 1 and noise entries of variance 1/n, a population singular value d produces an outlier sample singular value only if d > gamma^(1/4).

source
RandomMatrix.svdSpikeLocation — Function
svdSpikeLocation(d, gamma)

Almost-sure limit of the sample singular value generated by a population singular value d in the rectangular spiked model with gamma = p/n <= 1:

sqrt((d^2 + 1) * (1 + gamma / d^2))     if d > gamma^(1/4)

Below the threshold it sticks to the bulk edge 1 + sqrt(gamma).

source
RandomMatrix.svdSpikeOverlaps — Function
svdSpikeOverlaps(d, gamma)

Almost-sure limits (left, right) of the squared overlaps between the sample singular vectors and the population singular vectors for a supercritical population singular value d, with gamma = p/n <= 1 (left is the vector in R^p, right the one in R^n):

left  = (d^4 - gamma) / (d^2 * (d^2 + gamma))
right = (d^4 - gamma) / (d^2 * (d^2 + 1))

Both are zero below the threshold gamma^(1/4).

The spiked MANOVA (Jacobi) case

The same transition governs the double-Wishart (MANOVA) matrix $(A + B)^{-1} A$, whose bulk follows the Wachter law. With $A \sim W_p(\Sigma, n_1)$, $B \sim W_p(I, n_2)$ and aspect ratios $\gamma_1 = p/n_1$, $\gamma_2 = p/n_2$, a population spike $\theta$ of $\Sigma$ (bulk at 1) produces an outlier eigenvalue only outside the critical window $(\theta_-, \theta_+)$ with $\theta_\pm = (1 \pm \rho)/(1 - \gamma_2)$ and $\rho = \sqrt{\gamma_1 + \gamma_2 - \gamma_1\gamma_2}$ — the same $\rho$ as in the Wachter support edges. Inside the window the spike is absorbed and the sample eigenvalue sticks to the nearer Wachter edge (Wang & Yao, Ann. Statist. 45(1), 2017, Thm. 3.1, mapped from the Fisher matrix $B^{-1}A$ to the MANOVA eigenvalues).

RandomMatrix.manovaThreshold — Function
manovaThreshold(γ₁, γ₂)

Critical population spike for the BBP phase transition in a spiked MANOVA model: for A ~ W_p(Σ, n₁), B ~ W_p(I, n₂) with aspect ratios γ₁ = p / n₁ and γ₂ = p / n₂, a population spike θ (an eigenvalue of Σ, bulk at 1) yields an outlier eigenvalue of (A + B)⁻¹ A only if

\[\theta > \frac{1 + \rho}{1 - \gamma_2}, \qquad \rho = \sqrt{\gamma_1 + \gamma_2 - \gamma_1 \gamma_2}\]

(the same ρ as in the Wachter support). Spikes below 1 separate only under the lower critical value (1 - ρ) / (1 - γ₂); see manovaSpikeLocation.

source
RandomMatrix.manovaSpikeLocation — Function
manovaSpikeLocation(θ, γ₁, γ₂)

Almost-sure limit of the sample eigenvalue of (A + B)⁻¹ A generated by a population spike θ (an eigenvalue of Σ in A ~ W_p(Σ, n₁), bulk at 1), with aspect ratios γ₁ = p / n₁, γ₂ = p / n₂. With ρ = √(γ₁ + γ₂ - γ₁γ₂) the critical spikes are θ₊ = (1 + ρ) / (1 - γ₂) (see manovaThreshold) and θ₋ = (1 - ρ) / (1 - γ₂):

  • θ ≥ θ₊: the outlier sits above the Wachter support, at x = t / (1 + t) with t = (γ₂ / γ₁) φ(θ) and Wang & Yao's Fisher displacement φ(θ) = θ (θ - 1 + γ₁) / ((1 - γ₂) θ - 1).
  • θ ≤ θ₋: the outlier sits below the support, at the same map.
  • θ₋ < θ < θ₊: the spike is absorbed by the bulk; the sample eigenvalue sticks to the nearer Wachter edge x± = γ₂ (γ₁ ± ρ)² / (γ₁ + γ₂)² (the upper edge for θ ≥ 1, the lower for θ < 1).

The map is continuous at the critical values: at θ = θ₊ (resp. θ₋) it returns exactly x₊ (resp. x₋).

source
RandomMatrix.manovaSpikeVariance — Function
manovaSpikeVariance(θ, γ₁, γ₂, p; real=true)

Asymptotic variance of the outlier sample eigenvalue of (A + B)⁻¹ A generated by a supercritical population spike θ, for Gaussian populations: with x̂ the sample eigenvalue, √p (x̂ - manovaSpikeLocation(θ, γ₁, γ₂)) is asymptotically centred normal with variance p * manovaSpikeVariance(θ, γ₁, γ₂, p).

The formula is the delta method applied to the spiked Fisher CLT. For F = S₂⁻¹ S₁ (sample covariances with the same degrees of freedom), Dharmawansa, Johnstone & Onatski (2014, Prop. 11, Setting 1; the Gaussian case of Wang & Yao 2017, Thm. 4.1) give, with h = θ - 1 and ρ² = γ₁ + γ₂ - γ₁γ₂,

\[p\,\mathrm{Var}(\hat\varphi) \;\to\; \frac{2\rho^2 h^2 \theta^2 \bigl(h^2 - \gamma_2\theta^2 - \gamma_1\bigr)} {\bigl((1 - \gamma_2)\theta - 1\bigr)^4}, \qquad \hat\varphi \to \varphi(\theta)\]

the outlier of F. The MANOVA eigenvalue is x = t / (1 + t) with t = (γ₂ / γ₁) φ, so its variance picks up the Jacobian factor (γ₂ / γ₁)² / (1 + t)⁴. The same rational expression holds on both sides of the critical window (above θ₊ and below θ₋); both sides were validated against spiked MANOVA simulation (variance ratios within about 10% of 1 at p = 100–200 across a (θ, γ₁, γ₂) grid, on the Fisher and MANOVA scales alike). For complex data (real=false) the variance is halved, as in spikeVariance.

Returns NaN inside the critical window θ₋ ≤ θ ≤ θ₊, where the fluctuations are not Gaussian at the 1/p scale (the sample eigenvalue sticks to a Wachter edge).

source

Worked example

At $\gamma_1 = \gamma_2 = 0.5$ the upper critical spike is $\theta_+ \approx 3.73$: a spike of $\theta = 6$ separates to $0.943$ (above the Wachter upper edge $x_+ \approx 0.933$), a spike of $\theta = 2$ is inside the window and sticks to that edge, and a low spike of $\theta = 0.1$ separates below the bulk at $0.040$.

using RandomMatrix
(threshold = round(manovaThreshold(0.5, 0.5), digits = 3),
 outlier = round(manovaSpikeLocation(6.0, 0.5, 0.5), digits = 3),
 stuck = round(manovaSpikeLocation(2.0, 0.5, 0.5), digits = 3),
 lower = round(manovaSpikeLocation(0.1, 0.5, 0.5), digits = 3))
(threshold = 3.732, outlier = 0.943, stuck = 0.933, lower = 0.04)

Above the threshold the outlier's fluctuations are Gaussian at the $1/p$ scale (Dharmawansa, Johnstone & Onatski 2014, Prop. 11, pushed through the map from the Fisher matrix to the MANOVA eigenvalues), so at $p = 100$ the spike of $\theta = 6$ above fluctuates with standard deviation $\sqrt{\mathrm{manovaSpikeVariance}} \approx 0.0076$:

round(sqrt(manovaSpikeVariance(6.0, 0.5, 0.5, 100)), digits = 4)
0.0076

The spiked Wigner case

The additive analogue: $M = \sigma W/\sqrt{n} + A$ with $W$ a Wigner matrix (bulk the semicircle law on $[-2\sigma, 2\sigma]$) and $A$ a finite-rank deformation. A spike $\theta$ of $A$ produces an outlier eigenvalue only above the threshold $|\theta| > \sigma$, at $\theta + \sigma^2/\theta$, with eigenvector overlap $1 - \sigma^2/\theta^2$ (Capitaine, Donati-Martin & Féral, Ann. Probab. 37(1), 2009, Thm. 2.1). Below the threshold the spike sticks to the nearer semicircle edge.

RandomMatrix.wignerThreshold — Function
wignerThreshold(; sigma=1.0)

Critical spike size for the BBP phase transition in a spiked Wigner model: a spike theta of the deformation produces an outlier eigenvalue of sigma * W / sqrt(n) + A only if |theta| > sigma, where sigma^2 is the variance of the (unscaled) Wigner entries, so the semicircle bulk is supported on [-2 sigma, 2 sigma].

source
RandomMatrix.wignerSpikeLocation — Function
wignerSpikeLocation(theta; sigma=1.0)

Almost-sure limit of the sample eigenvalue generated by a spike theta of the deformation in a spiked Wigner model with noise scale sigma (semicircle bulk on [-2 sigma, 2 sigma]):

theta + sigma^2 / theta     if |theta| > sigma

For |theta| <= sigma the spike sticks to the nearer semicircle edge sign(theta) * 2 sigma (with theta = 0 returning 2 sigma), which is what this returns.

source
RandomMatrix.wignerSpikeOverlap — Function
wignerSpikeOverlap(theta; sigma=1.0)

Almost-sure limit of the squared overlap |dot(u_hat, v)|^2 between the sample eigenvector of the outlier and the spike direction v, for a spike theta with noise scale sigma:

1 - sigma^2 / theta^2     if |theta| > sigma

Zero at or below the threshold wignerThreshold: the sample eigenvector is asymptotically orthogonal to the spike direction.

source
RandomMatrix.wignerEstimateSpike — Function
wignerEstimateSpike(lambda; sigma=1.0)

Estimate the spike theta from an observed outlier sample eigenvalue lambda, by inverting wignerSpikeLocation:

theta = (lambda + sign(lambda) * sqrt(lambda^2 - 4 sigma^2)) / 2

For lambda inside the semicircle bulk [-2 sigma, 2 sigma] the spike is not identifiable and the threshold value on that side, sign(lambda) * sigma (with lambda = 0 returning sigma), is returned.

source
RandomMatrix.wignerSpikeVariance — Function
wignerSpikeVariance(theta, n; sigma=1.0, real=true, m4=nothing)

Asymptotic variance of the outlier sample eigenvalue generated by a supercritical spike theta (|theta| > sigma) in an n x n spiked Wigner model. Returns NaN at or below the threshold wignerThreshold, where the fluctuations are Tracy-Widom rather than Gaussian.

By default (Gaussian noise, or any delocalized spike direction) the fluctuations are Gaussian with (Capitaine-Donati-Martin-Feral 2009, Thm. 2.3)

Var(lambda_hat) = c * sigma^2 * (1 - sigma^2 / theta^2) / n,

with c = 2 for real data (real=true) and c = 1 for complex data: sqrt(n) (lambda_hat - wignerSpikeLocation(theta)) is asymptotically centred normal with variance n * Var(lambda_hat).

The fluctuations are non-universal when the spike points along a coordinate direction v = e_i and the entries are non-Gaussian (Capitaine-Donati-Martin-Feral 2009, Thm. 2.2): the limiting law of sqrt(n) (lambda_hat - rho) / (1 - sigma^2 / theta^2) is then the convolution of the diagonal-entry law with a Gaussian, and its variance picks up a fourth-cumulant term. Passing m4, the fourth moment of the noise entries (E[W_ij^4] in the real case, E[abs(W_ij)^4] in the complex case, for the unscaled entries of variance sigma^2; Gaussian values 3 sigma^4 real, 2 sigma^4 complex), returns the variance of that limiting law:

Var(lambda_hat) = (1 - sigma^2 / theta^2)^2 *
    (c * sigma^2 + kappa / theta^2 + c * sigma^4 / (theta^2 - sigma^2)) / n,

where kappa = m4 - 3 sigma^4 (real) or kappa = m4 - 2 sigma^4 (complex). At the Gaussian value of m4 this reduces exactly to the default formula above.

source
RandomMatrix.randSpikedWigner — Function
randSpikedWigner(n, spikes; sigma=1.0)

Sample an n x n spiked Wigner matrix sigma * W / sqrt(n) + sum_k theta_k v_k v_k', where W is a GOE matrix (see GOE, sampled with norm=true, so the bulk follows the semicircle law on [-2 sigma, 2 sigma]), spikes is a vector of spike sizes theta_k (positive spikes separate above the bulk, negative ones below, each only if |theta_k| > sigma), and the spike directions v_k are orthonormal and Haar-random. Returns a symmetric n x n matrix.

Examples

M = randSpikedWigner(400, [2.0])
eigmax(M)   # near wignerSpikeLocation(2.0) = 2.5
source

Worked example

At $\sigma = 1$ a spike of $\theta = 2$ is above the threshold, so it appears as an outlier near wignerSpikeLocation(2) = 2.5 with eigenvector overlap 0.75; a spike of $\theta = 0.7$ is below the threshold and sticks to the semicircle edge $2$.

using RandomMatrix
(threshold = wignerThreshold(), loc = wignerSpikeLocation(2.0),
 overlap = wignerSpikeOverlap(2.0),
 recovered = wignerEstimateSpike(wignerSpikeLocation(2.0)),
 stuck = wignerSpikeLocation(0.7))
(threshold = 1.0, loc = 2.5, overlap = 0.75, recovered = 2.0, stuck = 2.0)

A seeded simulation agrees, within the fluctuation scale sqrt(wignerSpikeVariance(2, 400)) ≈ 0.061:

M = randSpikedWigner(400, [2.0])
round(eigmax(M), digits = 2)
2.52

The outlier's fluctuations are Gaussian at the $1/\sqrt{n}$ scale with variance $2\sigma^2(1 - \sigma^2/\theta^2)/n$ for real data — unless the spike points along a coordinate direction and the entries are non-Gaussian: the limiting law is then non-universal and acquires a fourth-cumulant term (Capitaine-Donati-Martin-Féral 2009, Thm. 2.2), exposed through the m4 keyword of wignerSpikeVariance. For Rademacher entries ($m_4 = \sigma^4$) at $\theta = 2$ the coordinate-direction variance is 1.21875 / n, against the Gaussian 1.5 / n:

(gaussian = wignerSpikeVariance(2.0, 1), rademacher_e1 = wignerSpikeVariance(2.0, 1; m4 = 1.0))
(gaussian = 1.5, rademacher_e1 = 1.21875)
