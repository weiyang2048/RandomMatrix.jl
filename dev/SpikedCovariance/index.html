Spiked Covariance and the BBP Transition

In a spiked covariance model the population covariance has a bulk of eigenvalues at $\sigma^2$ plus a few larger spikes. With aspect ratio $\gamma = p/n$, the Baik–Ben Arous–Péché (BBP) transition says a spike $\ell$ is visible in the sample covariance — as an outlier eigenvalue with an eigenvector correlated with the population direction — only when $\ell > \sigma^2 (1 + \sqrt\gamma)$. Below the threshold the spike is swallowed by the Marčenko–Pastur bulk.

RandomMatrix.bbpThreshold — Function
bbpThreshold(gamma; sigma=1.0)

Critical population eigenvalue for the BBP phase transition in a spiked covariance model with aspect ratio gamma = p/n and bulk (noise) variance sigma^2. A population spike l yields an outlier sample eigenvalue only if l > bbpThreshold(gamma) = sigma^2 * (1 + sqrt(gamma)).

source
RandomMatrix.spikeLocation — Function
spikeLocation(l, gamma; sigma=1.0)

Almost-sure limit of the sample eigenvalue generated by a population spike l (an eigenvalue of the population covariance, bulk at sigma^2) with aspect ratio gamma = p/n:

l * (1 + gamma * sigma^2 / (l - sigma^2))     if l > sigma^2 (1 + sqrt(gamma))

Below the BBP threshold the spike sticks to the upper Marcenko-Pastur edge sigma^2 (1 + sqrt(gamma))^2, which is what this returns.

source
RandomMatrix.spikeOverlap — Function
spikeOverlap(l, gamma; sigma=1.0)

Almost-sure limit of the squared overlap |dot(u_hat, u)|^2 between the sample eigenvector of the outlier and its population counterpart, for a population spike l with aspect ratio gamma = p/n and bulk variance sigma^2:

(1 - gamma * sigma^4 / (l - sigma^2)^2) / (1 + gamma * sigma^2 / (l - sigma^2))

Zero below the BBP threshold: the sample eigenvector is asymptotically orthogonal to the population direction.

source
RandomMatrix.estimateSpike — Function
estimateSpike(lambda, gamma; sigma=1.0)

Estimate the population spike l from an observed outlier sample eigenvalue lambda, by inverting spikeLocation:

l = sigma^2 * ((lam + 1 - gamma) + sqrt((lam + 1 - gamma)^2 - 4 lam)) / 2,
lam = lambda / sigma^2

For lambda at or below the Marcenko-Pastur edge the spike is not identifiable and the BBP threshold value is returned.

source
RandomMatrix.spikeVariance — Function
spikeVariance(l, gamma, n; sigma=1.0, real=true)

Asymptotic variance of the outlier sample eigenvalue generated by a supercritical population spike l (Paul 2007): with lr = l / sigma^2,

Var(lambda_hat) = sigma^4 * 2 lr^2 (1 - gamma / (lr - 1)^2) / n

for real data; sqrt(n) (lambda_hat - spikeLocation(l, gamma)) is asymptotically centred normal with variance n * Var(lambda_hat). For complex data (real=false) the variance is halved. Returns NaN at or below the BBP threshold, where the fluctuations are Tracy-Widom rather than Gaussian.

source
RandomMatrix.randSpikedCovariance — Function
randSpikedCovariance(p, n, spikes; sigma=1.0)

Sample covariance matrix (1/n) X X' of p x n Gaussian data whose population covariance has eigenvalues spikes (a vector of spike eigenvalues, each > sigma^2) on top of a bulk at sigma^2, with random ( Haar ) population eigenvectors. Returns a symmetric p x p matrix.

Examples

S = randSpikedCovariance(200, 400, [4.0])
eigmax(S)   # near spikeLocation(4.0, 0.5) = 4.667
source

Worked example

At $\gamma = 0.5$ a spike of $\ell = 4$ is well above the BBP threshold, so it should appear as an outlier near spikeLocation(4, 0.5) = 4.667 with eigenvector overlap about 0.81; a spike of $\ell = 1.3$ is below the threshold and sticks to the Marčenko–Pastur edge $(1 + \sqrt\gamma)^2 \approx 2.914$.

using RandomMatrix
gamma = 0.5
(threshold = bbpThreshold(gamma), loc = spikeLocation(4.0, gamma),
 overlap = round(spikeOverlap(4.0, gamma), digits = 3),
 recovered = estimateSpike(spikeLocation(4.0, gamma), gamma))
(threshold = 1.7071067811865475, loc = 4.666666666666667, overlap = 0.81, recovered = 4.0)

A seeded simulation agrees, within the fluctuation scale sqrt(spikeVariance(4, 0.5, 400)) ≈ 0.27 given by Paul's formula:

S = randSpikedCovariance(200, 400, [4.0])
round(eigmax(S), digits = 2)
4.45

The rectangular case

For singular values of rectangular data the transition is at $d > \gamma^{1/4}$ (Benaych-Georges & Nadakuditi).

RandomMatrix.svdThreshold — Function
svdThreshold(gamma)

Critical population singular value for the rectangular BBP transition (Benaych-Georges & Nadakuditi): for p x n data with gamma = p/n <= 1 and noise entries of variance 1/n, a population singular value d produces an outlier sample singular value only if d > gamma^(1/4).

source
RandomMatrix.svdSpikeLocation — Function
svdSpikeLocation(d, gamma)

Almost-sure limit of the sample singular value generated by a population singular value d in the rectangular spiked model with gamma = p/n <= 1:

sqrt((d^2 + 1) * (1 + gamma / d^2))     if d > gamma^(1/4)

Below the threshold it sticks to the bulk edge 1 + sqrt(gamma).

source
RandomMatrix.svdSpikeOverlaps — Function
svdSpikeOverlaps(d, gamma)

Almost-sure limits (left, right) of the squared overlaps between the sample singular vectors and the population singular vectors for a supercritical population singular value d, with gamma = p/n <= 1 (left is the vector in R^p, right the one in R^n):

left  = (d^4 - gamma) / (d^2 * (d^2 + gamma))
right = (d^4 - gamma) / (d^2 * (d^2 + 1))

Both are zero below the threshold gamma^(1/4).

source

The spiked MANOVA (Jacobi) case

The same transition governs the double-Wishart (MANOVA) matrix $(A + B)^{-1} A$, whose bulk follows the Wachter law. With $A \sim W_p(\Sigma, n_1)$, $B \sim W_p(I, n_2)$ and aspect ratios $\gamma_1 = p/n_1$, $\gamma_2 = p/n_2$, a population spike $\theta$ of $\Sigma$ (bulk at 1) produces an outlier eigenvalue only outside the critical window $(\theta_-, \theta_+)$ with $\theta_\pm = (1 \pm \rho)/(1 - \gamma_2)$ and $\rho = \sqrt{\gamma_1 + \gamma_2 - \gamma_1\gamma_2}$ — the same $\rho$ as in the Wachter support edges. Inside the window the spike is absorbed and the sample eigenvalue sticks to the nearer Wachter edge (Wang & Yao, Ann. Statist. 45(1), 2017, Thm. 3.1, mapped from the Fisher matrix $B^{-1}A$ to the MANOVA eigenvalues).

RandomMatrix.manovaThreshold — Function
manovaThreshold(γ₁, γ₂)

Critical population spike for the BBP phase transition in a spiked MANOVA model: for A ~ W_p(Σ, n₁), B ~ W_p(I, n₂) with aspect ratios γ₁ = p / n₁ and γ₂ = p / n₂, a population spike θ (an eigenvalue of Σ, bulk at 1) yields an outlier eigenvalue of (A + B)⁻¹ A only if

\[\theta > \frac{1 + \rho}{1 - \gamma_2}, \qquad \rho = \sqrt{\gamma_1 + \gamma_2 - \gamma_1 \gamma_2}\]

(the same ρ as in the Wachter support). Spikes below 1 separate only under the lower critical value (1 - ρ) / (1 - γ₂); see manovaSpikeLocation.

source
RandomMatrix.manovaSpikeLocation — Function
manovaSpikeLocation(θ, γ₁, γ₂)

Almost-sure limit of the sample eigenvalue of (A + B)⁻¹ A generated by a population spike θ (an eigenvalue of Σ in A ~ W_p(Σ, n₁), bulk at 1), with aspect ratios γ₁ = p / n₁, γ₂ = p / n₂. With ρ = √(γ₁ + γ₂ - γ₁γ₂) the critical spikes are θ₊ = (1 + ρ) / (1 - γ₂) (see manovaThreshold) and θ₋ = (1 - ρ) / (1 - γ₂):

  • θ ≥ θ₊: the outlier sits above the Wachter support, at x = t / (1 + t) with t = (γ₂ / γ₁) φ(θ) and Wang & Yao's Fisher displacement φ(θ) = θ (θ - 1 + γ₁) / ((1 - γ₂) θ - 1).
  • θ ≤ θ₋: the outlier sits below the support, at the same map.
  • θ₋ < θ < θ₊: the spike is absorbed by the bulk; the sample eigenvalue sticks to the nearer Wachter edge x± = γ₂ (γ₁ ± ρ)² / (γ₁ + γ₂)² (the upper edge for θ ≥ 1, the lower for θ < 1).

The map is continuous at the critical values: at θ = θ₊ (resp. θ₋) it returns exactly x₊ (resp. x₋).

source
RandomMatrix.manovaSpikeVariance — Function
manovaSpikeVariance(θ, γ₁, γ₂, p; real=true)

Asymptotic variance of the outlier sample eigenvalue of (A + B)⁻¹ A generated by a supercritical population spike θ, for Gaussian populations: with x̂ the sample eigenvalue, √p (x̂ - manovaSpikeLocation(θ, γ₁, γ₂)) is asymptotically centred normal with variance p * manovaSpikeVariance(θ, γ₁, γ₂, p).

The formula is the delta method applied to the spiked Fisher CLT. For F = S₂⁻¹ S₁ (sample covariances with the same degrees of freedom), Dharmawansa, Johnstone & Onatski (2014, Prop. 11, Setting 1; the Gaussian case of Wang & Yao 2017, Thm. 4.1) give, with h = θ - 1 and ρ² = γ₁ + γ₂ - γ₁γ₂,

\[p\,\mathrm{Var}(\hat\varphi) \;\to\; \frac{2\rho^2 h^2 \theta^2 \bigl(h^2 - \gamma_2\theta^2 - \gamma_1\bigr)} {\bigl((1 - \gamma_2)\theta - 1\bigr)^4}, \qquad \hat\varphi \to \varphi(\theta)\]

the outlier of F. The MANOVA eigenvalue is x = t / (1 + t) with t = (γ₂ / γ₁) φ, so its variance picks up the Jacobian factor (γ₂ / γ₁)² / (1 + t)⁴. The same rational expression holds on both sides of the critical window (above θ₊ and below θ₋); both sides were validated against spiked MANOVA simulation (variance ratios within about 10% of 1 at p = 100–200 across a (θ, γ₁, γ₂) grid, on the Fisher and MANOVA scales alike). For complex data (real=false) the variance is halved, as in spikeVariance.

Returns NaN inside the critical window θ₋ ≤ θ ≤ θ₊, where the fluctuations are not Gaussian at the 1/p scale (the sample eigenvalue sticks to a Wachter edge).

source

Worked example

At $\gamma_1 = \gamma_2 = 0.5$ the upper critical spike is $\theta_+ \approx 3.73$: a spike of $\theta = 6$ separates to $0.943$ (above the Wachter upper edge $x_+ \approx 0.933$), a spike of $\theta = 2$ is inside the window and sticks to that edge, and a low spike of $\theta = 0.1$ separates below the bulk at $0.040$.

using RandomMatrix
(threshold = round(manovaThreshold(0.5, 0.5), digits = 3),
 outlier = round(manovaSpikeLocation(6.0, 0.5, 0.5), digits = 3),
 stuck = round(manovaSpikeLocation(2.0, 0.5, 0.5), digits = 3),
 lower = round(manovaSpikeLocation(0.1, 0.5, 0.5), digits = 3))
(threshold = 3.732, outlier = 0.943, stuck = 0.933, lower = 0.04)

Above the threshold the outlier's fluctuations are Gaussian at the $1/p$ scale (Dharmawansa, Johnstone & Onatski 2014, Prop. 11, pushed through the map from the Fisher matrix to the MANOVA eigenvalues), so at $p = 100$ the spike of $\theta = 6$ above fluctuates with standard deviation $\sqrt{\mathrm{manovaSpikeVariance}} \approx 0.0076$:

round(sqrt(manovaSpikeVariance(6.0, 0.5, 0.5, 100)), digits = 4)
0.0076
